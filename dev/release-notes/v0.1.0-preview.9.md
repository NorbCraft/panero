# Panero 0.1.0 preview 9

**Panero is an independent fork of Krusader. It is not affiliated with or endorsed by KDE or the Krusader maintainers.**

Preview for **Zorin OS 18.1** and other **Ubuntu 24.04** based systems (x86_64).
It upgrades earlier previews in place; settings and cloud sign-ins are kept.

## Smooth cloud browsing

- After a drive connects, Panero reads its **whole folder list** in the
  background, like OneDrive on Windows. Afterwards opening any folder needs no
  network: walking every folder of the owner's drives took 6 ms.
- Cloud folders are read **in the background**: Panero never freezes while
  browsing, shows ">> Reading..." when a folder still has to come from the
  cloud, and going elsewhere cancels the wait.
- The folder you open is **checked for changes in the background** (and every
  30 seconds) and updated when something changed. **Ctrl+R** re-reads only
  that folder instead of forgetting the whole drive.
- Subfolders are read ahead a few at a time; the folder tree no longer asks
  the cloud for its size on every folder change.
- OneDrive's locked **Personal Vault** no longer stops reading the drive.

## Google Drive: use your own client ID

Measured on the owner's Google Drive: Google answers rclone's **shared**
client ID with "quota exceeded" and one folder listing takes 17–35 seconds.
That ID is also being retired during 2026. Add Google Drive with **Use my own
Google client ID**, or right-click an existing Google Drive > **Use Own Google
Client ID (Faster)...** (one new sign-in). How to create the ID:
<https://rclone.org/drive/#making-your-own-client-id>. The secret goes only
through rclone's private socket into the encrypted configuration.

## New

- **Folder badge**: green check when everything inside is on this device.
- **Rename...** a cloud drive in the sidebar (only the name Panero shows).
- The drive's top folder is the top of browsing: the path bar starts with the
  drive's name, no "..", **Up** stops there.

## Security

- Panero controls each mount through rclone's remote control on a **unix
  socket** in its private runtime folder (never a network port), with a random
  password per mount; rclone gets only a hash of it, in a private file.
- No secret on any command line or in any environment (checked by the test
  suite's process scanner during all cloud tests).

## Install

```bash
sudo apt install ./panero_0.1.0.preview.9-1_amd64.deb
```

Restart Panero after installing so the drives are mounted with the new
settings.

## Tested

- ctest (7 suites, 46 cloud unit tests) and 16 cloud security tests: remote
  control socket (wrong password refused, nothing in the command line or
  environment), whole-tree reading, folder refresh, folder badges, own Google
  client (fake OAuth server).
- GUI test under Xvfb with a stand-in drive: path bar, no "..", Up stops at
  the top folder, Rename, folder badge.
- Read-only on the owner's Google Drive and OneDrive (separate read-only
  mount, nothing written): whole tree read, then every folder in 6 ms.
