# Panero 0.1.0 preview 1

**Panero is an independent fork of Krusader. It is not affiliated with or endorsed by KDE or the Krusader maintainers.**

First public preview of Panero, a native twin-panel file manager based on
Krusader 2.8.1 (Qt 5 / KDE Frameworks 5), for **Zorin OS 18.1** and other
**Ubuntu 24.04** based systems on x86_64. This is a preview: it builds on a
mature file-management engine, but the new parts have only had a short test
period.

## What is new compared to Krusader

- Commander workflow: the cursor and the marked files are independent; short
  right-click marks, holding the right button opens the normal context menu.
- Clear cursor (blue frame) and marks (red with a check badge), alternating
  rows, adjustable row height (compact to spacious), light and dark appearance
  following the desktop.
- Thumbnails view with real previews; Extension column.
- Left sidebar with pinned folders and a folder tree for the active panel;
  drive selector on each panel.
- Compare by content with KDiff3, with an "Install KDiff3?" offer.
- Simplified toolbar; all original Krusader menus, F-keys and features kept.
- Installs next to Krusader without touching its files or settings; optional
  import of Krusader settings.

See USER-GUIDE.md in the source for a short guide.

## Install

Download `panero_0.1.0.preview.1-1_amd64.deb` below (package version `0.1.0~preview.1-1`;
GitHub shows `~` as `.` in file names) and open it with the
Software installer, or in a terminal:

```bash
sudo apt install ./panero_0.1.0.preview.1-1_amd64.deb
```

Uninstall: `sudo apt remove panero` (settings in `~/.config/panerorc` and
`~/.local/share/panero/` are kept).
