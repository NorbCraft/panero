# Panero 0.1.0 preview 1

**Panero is an independent fork of Krusader. It is not affiliated with or endorsed by KDE or the Krusader maintainers.**

First public preview of Panero, a native twin-panel file manager based on
Krusader 2.8.1 (Qt 5 / KDE Frameworks 5), for **Zorin OS 18.1** and other
**Ubuntu 24.04** based systems on x86_64. This is a preview: it builds on a
mature file-management engine, but the new parts have only had a short test
period.

## What is new compared to Krusader

- Commander workflow: the cursor and the marked files are independent; short
  right-click marks, holding the right button opens the normal context menu.
- Clear cursor (blue frame) and marks (red with a check badge), alternating
  rows, adjustable row height (compact to spacious), light and dark appearance
  following the desktop.
- Thumbnails view with real previews; Extension column.
- Left sidebar with pinned folders and a folder tree for the active panel;
  drive selector on each panel.
- Compare by content with KDiff3, with an "Install KDiff3?" offer.
- Simplified toolbar; all original Krusader menus, F-keys and features kept.
- Installs next to Krusader without touching its files or settings; optional
  import of Krusader settings.

See USER-GUIDE.md in the source for a short guide.

## Install

Download `panero_0.1.0.preview.1-1_amd64.deb` below (package version `0.1.0~preview.1-1`;
GitHub shows `~` as `.` in file names) and open it with the
Software installer, or in a terminal:

```bash
sudo apt install ./panero_0.1.0.preview.1-1_amd64.deb
```

Uninstall: `sudo apt remove panero` (settings in `~/.config/panerorc` and
`~/.local/share/panero/` are kept).

## Tested on

- **Zorin OS 18.1** (x86_64, GNOME, Wayland): Panero started on the real desktop via
  XWayland (Qt 5's default on GNOME) and natively (`QT_QPA_PLATFORM=wayland`), following
  the desktop's dark mode. Functional GUI tests ran on the same machine under Xvfb with an
  isolated profile: marks/cursor and right-button gestures, real file operations
  (copy, overwrite cancel, new folder, rename, move, Trash and restore, pack/unpack,
  search - 17/17), thumbnails with real previews, light/dark, density, 2x scaling,
  KDiff3 comparison.
- **Clean Ubuntu 24.04 containers** (the base of Zorin 18.1): `apt install` of the .deb
  with dependency resolution, side by side with the distro `krusader` package (both
  install orders, no shared files), upgrade from an older Panero package, remove and
  purge; the "Install KDiff3?" flow with a real PackageKit/PolicyKit stack (installed and
  resumed the comparison; refused authorisation; broken software sources).
- Automated tests on every change (GitHub Actions, Ubuntu 24.04).

Not tested: a native Xorg session (only XWayland/Xvfb), Linux Mint and other
distributions, real removable/unmounted drives for pins and the drive selector, a
HiDPI monitor (only Qt scale factor 2).

## Known limitations

- This is a preview; the new Panero parts have had a short test period.
- The built-in handbook (Help) still describes Krusader 2.8; some translations may
  still say "Krusader", and new Panero texts are English only.
- Qt 5 runs through XWayland on GNOME by default. With `QT_QPA_PLATFORM=wayland` it runs
  natively, but window decorations are then drawn by Qt.
- Without a colourful desktop icon theme, the small Breeze fallback icons are
  monochrome (Zorin's own theme is used on Zorin).
- The "Install KDiff3?" offer needs PackageKit (installed by default on Zorin);
  otherwise Panero explains how to install KDiff3. Root mode needs `kde-cli-tools`.
- GitHub shows `~` in the package file name as `.`; the package version is
  `0.1.0~preview.1-1`.
