# Panero 0.1.0 preview 8

**Panero is an independent fork of Krusader. It is not affiliated with or endorsed by KDE or the Krusader maintainers.**

Preview for **Zorin OS 18.1** and other **Ubuntu 24.04** based systems (x86_64).
It upgrades earlier previews in place; settings and cloud sign-ins are kept.

## Faster cloud browsing

- Panero no longer **opens every file** of a cloud folder to guess its type
  (each open started a download): on cloud drives the type comes from the
  extension. Measured on a Google Drive folder: 48 file opens before, none now.
- **Free space** of a cloud drive is read once and refreshed in the background
  instead of asking the cloud on every folder change.
- **Folder listings are kept** for an hour on Google Drive, OneDrive, Dropbox
  and Box (they report changes, checked every 30 seconds), and Panero lists the
  **next folder level ahead** in the background, so opening a subfolder is
  instant. **Ctrl+R** fetches the current folder again from the cloud.

## New

- Right-click files or folders on a cloud drive: **Make Available Offline**
  (download now, with a progress window) and **Free Up Space** (remove the
  downloaded copies; files with pending uploads are kept). Synced copies of
  folders are now **Always Keep on This Device (Synced Copy)**.
- **Google Docs, Sheets and Slides** (shown as 0 B, because Google stores no
  file for them) open in Google's editor in the browser; right-click > **Save
  a Copy as Office File in Other Panel**.
- **Progress windows** while a new cloud drive is set up and while a drive
  connects, instead of a window that looks frozen.

## Install

```bash
sudo apt install ./panero_0.1.0.preview.8-1_amd64.deb
```

Restart Panero after installing so the drives are mounted with the new
settings.

## Tested

- ctest (7 suites, 44 cloud unit tests) and 16 cloud security tests, including
  Make Available Offline / Free Up Space on a test drive.
- On the owner's Google Drive and OneDrive, only inside a `test-panero` folder
  (created and removed again): upload through the drive, free up the local
  copies, read back identical content.
- Panero on a Google Drive folder: no file opened while listing.
- Package tests in clean Ubuntu 24.04 containers.
