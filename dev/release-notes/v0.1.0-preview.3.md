# Panero 0.1.0 preview 3

**Panero is an independent fork of Krusader. It is not affiliated with or endorsed by KDE or the Krusader maintainers.**

Third preview of Panero for **Zorin OS 18.1** and other **Ubuntu 24.04** based
systems (x86_64). It upgrades earlier previews in place; settings are kept.

## Changes since preview 2

- **Modern look**: panels are rounded cards and the active one is outlined in
  the accent colour. The drive button is a small chip next to the path, and
  free space sits in the panel's bottom row. Tabs and column headers are
  quieter.
- **Menu button ☰** at the right end of the toolbar instead of the menu bar.
  All menus are still there; **Settings > Show Menubar** brings the menu bar
  back.
- **One toolbar**, icons only, medium size: one setting resizes all buttons.
  **View & Colors** sits at the right edge. The sidebar button is back to its
  preview 1 icon, twice as wide. The Details | Thumbnails toggle is icon-only
  and follows the toolbar size.
- **Upgrade fix**: if you changed a toolbar setting in an earlier preview,
  Panero kept that old toolbar. Now the old layout is replaced on upgrade (a
  backup is saved as `paneroui.rc.bak`) and your custom shortcuts are kept.
- **Folder tree**: "Start at Home" now always starts at Home while you are
  inside Home. Before, it sometimes started at Documents, Downloads, ... A
  click opens a folder and unfolds it; a second click on the open folder folds
  it. Rows are 24 px with 22 px icons.
- **Pins**: a pin is highlighted only while exactly its folder is shown.
- **Zoom**: Ctrl+mouse wheel in Details switches to Thumbnails. Zooming out of
  the smallest thumbnails returns to Details. The toggle button follows.
- **Space** on a folder also calculates and shows its size, as in Krusader and
  Total Commander.
- **View & Colors**: new **active panel and selection** colour (default:
  Krusader's blue), and **Selection: Panero or Krusader** (the original
  Krusader mouse selection).
- The sidebar's "Opens in: … panel" line is removed.

## Install

Download `panero_0.1.0.preview.3-1_amd64.deb` below (package version
`0.1.0~preview.3-1`; GitHub shows `~` as `.` in file names). Open it with the
Software installer, or run this in a terminal in the download folder:

```bash
sudo apt install ./panero_0.1.0.preview.3-1_amd64.deb
```

Uninstall: `sudo apt remove panero`.

## Tested

- Automated tests (ctest, 5 suites) and the GUI file operation test (copy,
  overwrite cancel, new folder, rename, move, Trash and restore, pack/unpack,
  search: 17/17) on Zorin OS 18.1 under Xvfb.
- The new behaviour, driven in the real app under Xvfb: Space folder size,
  tree unfold/fold and Home root, pin highlight, Ctrl+wheel zoom with the
  toggle, menu button, View & Colors options, "Use Panero's look" off, and the
  upgrade from a preview 1 toolbar layout with a custom shortcut.
- Package tests in clean Ubuntu 24.04 containers (install, coexistence with
  Krusader, upgrade, remove/purge).

See the preview 1 release notes for the full feature list, tested environments
and known limitations; they still apply.
