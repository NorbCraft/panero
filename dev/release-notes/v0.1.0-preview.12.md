# Panero 0.1.0 preview 12

**Panero is an independent fork of Krusader. It is not affiliated with or endorsed by KDE or the Krusader maintainers.**

Preview for **Zorin OS 18.1** and other **Ubuntu 24.04** based systems (x86_64),
and for **Windows 10/11** (x64), now also with an **installer**. It upgrades
earlier previews in place; settings and cloud sign-ins are kept.

## Windows: cloud folders like in Explorer

- Panero finds the cloud apps connected on the PC (OneDrive, OneDrive for
  work or school, Google Drive for desktop, Dropbox and other apps that use
  Windows' cloud files) and lists them in the sidebar's **Cloud** section,
  with their own icons. The section is there only while a cloud folder
  exists (Quick Settings > Show the Cloud section). Right-click: Open in
  Other Panel, **Pin**.
- **Browsing never downloads.** Online-only files are not opened for their
  type, icon or preview; they get the icon of their file type. A file is
  downloaded only when you open, view (F3) or edit (F4) it, as in Explorer.
- Badges as in Explorer: a cloud for online-only, a green outline check for
  files on this device, a filled green check for files always kept.
- Right-click inside a cloud folder: **Always Keep on This Device** (a check
  box, also for whole folders) and **Free Up Space** (in OneDrive and Dropbox
  folders these are the apps' own items).

## Windows: Explorer's right-click menu

- Right-click shows Explorer's own menu for the marked files, or the folder's
  menu on empty space: Open with, Send to, New, Share, Properties and the
  items other programs add (7-Zip, Visual Studio...). Shift+right-click shows
  the extended items as in Explorer.
- Panero's items on top: **Copy to other panel** (F5), **Move to other
  panel** (F6), **Copy Path**, **Open Terminal Here**, and **Panero Menu**
  for Panero's full previous menu.
- Rename starts Panero's own rename (Multi-Rename for several files); Open
  on a folder enters it in the panel; Delete goes to the Recycle Bin as in
  Explorer.
- In OneDrive and Dropbox folders their own offline items are used; Panero
  adds *Always Keep on This Device* / *Free Up Space* only for clouds that
  have none. Opening the menu never downloads online-only files.
- Archives, the Recycle Bin, search results and network locations keep
  Panero's menu.

## Windows: other fixes and the installer

- Folder icons for every folder: inetpub, PerfLogs, Windows and the others
  could show no icon, in the panels and in the folder tree. OneDrive is no
  longer drawn faded in the folder tree.
- `panero-0.1.0-preview.12-windows-x64-setup.exe` installs Panero for your
  user only, without administrator rights, with a Start menu entry (desktop
  icon optional) and an uninstaller. A newer installer **upgrades in place**
  and keeps your settings.
- The portable ZIP stays for those who prefer it.
- The files are not signed yet, so Windows SmartScreen warns on the first
  start (More info > Run anyway).

## Drive buttons

- Quick Settings > **Drive buttons**: *Icon and name*, or *Letter only* on
  Windows (`C:`, `D:`, as in Total Commander) / *Icon only* on Linux.
- A **Network** button: on Linux it opens the network (`smb:/`) when Samba
  browsing is installed; on Windows it lists the network drives and Network
  Locations and offers *Open Network Path...*.

## Linux: Windows 11 icons

Quick Settings > **Icon theme: Windows 11** gives Panero Windows 11 style
icons (yellow folders, Windows-like drives and file types) without changing
the rest of the desktop. The dark look uses the theme's dark variant. The
theme is the [Win11 icon theme](https://github.com/yeyushengfan258/Win11-icon-theme)
by yeyushengfan258 (GPL-3.0), bundled with Panero; its licence is in
`/usr/share/doc/panero/win11-icon-theme/`. Panero restarts to apply it.

## Install (Linux)

```bash
sudo apt install ./panero_0.1.0.preview.12-1_amd64.deb
```
