# Panero 0.1.0 preview 13

**Panero is an independent fork of Krusader. It is not affiliated with or endorsed by KDE or the Krusader maintainers.**

Preview for **Zorin OS 18.1** and other **Ubuntu 24.04** based systems (x86_64)
and for **Windows 10/11** (x64, installer or portable ZIP). It upgrades
earlier previews in place; settings and cloud sign-ins are kept.

## Quick View (Ctrl+Q)

The toolbar's new **Quick View** button (or **Ctrl+Q**) turns the other panel
into a viewer of the file under the cursor; it follows the cursor as you move.
Press it again to get the panel back as it was. **Tab** moves into the viewer
(scroll, search in text), Tab or Esc back.

- **Images**: fit to the panel, zoom (+ / - / 0 / 1, Ctrl+wheel), drag to
  pan, animated GIF/WebP play, size and photo date.
- **Text and code** with syntax colours and line numbers (first 2 MB).
- **Folders**: total size, number of files and folders, largest items.
- **Archives**: their contents.
- **PDF** (Linux): the pages.
- **Audio and video**: a simple player.
- Anything else: name, type, size, dates, and a hex view on request.
- **Cloud and online-only files are never loaded by moving the cursor**: the
  viewer shows the size and "Press Space to load".

## Copying, moving and Undo

- Every copy, move, delete or pack opens a **progress window** as in
  Krusader: what and where, speed, time left, **Pause**, **Keep in
  Background**, **Cancel**. The progress inside the target panel is gone.
- While anything runs, a **jobs button** with a progress ring sits on the
  toolbar; its menu lists all running jobs and reopens their windows. A short
  notice appears when a job in the background ends.
- **Undo (Ctrl+Z)** for move, rename, copy, new folder and delete to the
  Trash / Recycle Bin.
- **Marks are cleared** after copy, move, pack, open and copying to or from
  the other panel, as in Total Commander.
- **Space on a folder** shows its size in the Size column (and marks it).

## Settings

- **One Settings window** (**Ctrl+,**): Panero's pages first (Appearance,
  Panels, Mouse & Keys, Drives & Cloud, Windows integration on Windows), then
  Krusader's pages under **Advanced**. Krusader options that Panero replaces
  are hidden or point to the Panero page that sets them, so no option silently
  does nothing anymore.
- **Quick Settings** (the gear) is a short popup again: Light/Dark/System,
  icons, density, hidden files, drive buttons, Cloud section, thumbnails and
  **All Settings…**.
- **First-start assistant** for new users (look, drive buttons, Cloud
  section, mouse selection); Help > First-Start Assistant shows it again.
- Choosing an **icon theme resets the folder colour** to the theme's own; a
  colour can still be picked afterwards.
- **Transparent** is an option for the marked background; the cursor row is
  transparent by default (outline only).
- **Pinned replaces the bookmarks**: your Krusader bookmarks are copied into
  Pinned once (the bookmarks file is kept, with a backup); **Ctrl+D** shows the
  Pinned list as a menu, **Ctrl+B** pins the current folder.
- A **Tools** menu collects the less used tools; the Mount Manager (replaced
  by the drive buttons and drive menus) and an empty User Actions menu are
  hidden.

## Your findings, fixed

- **Drag and drop into the browser**: dropping files from Panero into the
  Flatpak Firefox (or any Flatpak/Snap app) failed with "File not found"
  because the sandbox cannot see your folders. Panero now hands the files over
  through the desktop's document portal, as the system file manager does.
- **"The file or folder krarc:/ does not exist"** when opening a zip: gone.
- **Dialogs and error messages** open centred on the Panero window and stay on
  top of it (they could appear anywhere or fall behind it).
- **Right-click on a drive** (drive buttons, drive list, Pinned): on Linux
  Properties (with the usage), Mount/Unmount, Safely Remove, Eject and
  **Format or Edit in Disks…**; on Windows **Explorer's drive menu**
  (Properties, Format, Eject, …) with Panero's items on top.
- **Documents, Downloads, Pictures …** show their own icons in the panels and
  in Pinned too, from whichever icon theme you use.
- **Double-click the divider** between the panels: 50 / 50.
- **Back and Forward** are on the toolbar, right of Up.
- **Thumbnail view**: finer zoom steps (48, 56, 64, 72, 80, 96 … 384 px) and
  the frame is the same on all four sides.
- **Bigger app icon** on the desktop and taskbar.
- **Windows**: the Cloud section appears again for those who used preview 11
  or older; OneDrive folders get a tick only when all their content is on
  the PC, as in Explorer; **Settings / Quick Settings: right-click menu**
  Explorer menu or Panero menu.

## Faster and lighter

- **Faster start**: Krusader scanned every device on the system at start and
  on every change of drive (0.3–0.7 s each on a typical PC). The window now
  appears sooner and does not freeze right after.
- **Cloud folders**: a folder you visited shows its last contents at once when
  you go back (then updates if something changed); no thumbnails are made on
  cloud drives automatically (each one downloaded the whole file); a freeze in
  the right-click menu on cloud files (while rclone was busy) is fixed.

## Windows: packing and unpacking

Alt+F5 / Alt+F9 pack and unpack **zip, 7z and tar** (gz, bz2, xz), and **rar**
archives can be unpacked, with the bundled 7-Zip (its licence is in the
licences archive).

## Install

Linux:

```bash
sudo apt install ./panero_0.1.0.preview.13-1_amd64.deb
```

Windows: `panero-0.1.0-preview.13-windows-x64-setup.exe` (per user, upgrades
an installed Panero, keeps settings) or the portable ZIP. Not signed yet:
SmartScreen warns on the first start (More info > Run anyway).
