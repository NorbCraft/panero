# Panero 0.1.0 preview 6

**Panero is an independent fork of Krusader. It is not affiliated with or endorsed by KDE or the Krusader maintainers.**

Bug-fix preview for **Zorin OS 18.1** and other **Ubuntu 24.04** based systems
(x86_64). It upgrades earlier previews in place; settings and cloud sign-ins
are kept.

## Fixed

- **OneDrive sign-in stayed at "Waiting for the sign-in to finish…"** after
  signing in in the browser. After the browser step rclone sets up the drive;
  when that failed (for example because the account's drives could not be
  listed) it silently tried again forever. Panero now notices this, stops it
  and shows rclone's message with a hint, and the setup has a time limit. The
  dialog says *Signed in. Finishing the setup…* once the browser part is done.
- **OneDrive access**: preview 5 asked Microsoft for access to all files,
  including files shared with you, although the dialog said "your own files".
  Panero now asks only for what the dialog says (*Also files others shared with
  me* adds shared files). After signing in, Panero makes sure the drive is the
  account's main OneDrive.

## New

- **Google Drive** and **OneDrive** icons in *Add Cloud* and in the sidebar.

## Install

Download `panero_0.1.0.preview.6-1_amd64.deb` below (package version
`0.1.0~preview.6-1`) and open it with the Software installer, or:

```bash
sudo apt install ./panero_0.1.0.preview.6-1_amd64.deb
```

If a half-finished "OneDrive" entry from preview 5 is in the sidebar, right-click
it > **Sign Out and Remove** before adding OneDrive again.

## Tested

- ctest (7 suites, 42 cloud unit tests) and the 16 cloud security tests, now
  including a complete browser sign-in against a local fake OAuth server: the
  Google Drive setup finishes with the key stored encrypted, and a OneDrive
  setup whose drive listing fails is stopped with rclone's message instead of
  hanging.
- Package tests in clean Ubuntu 24.04 containers.

**Not tested**: sign-in to real accounts (none available to the developer).
