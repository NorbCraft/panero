# Panero 0.1.0 preview 11

**Panero is an independent fork of Krusader. It is not affiliated with or endorsed by KDE or the Krusader maintainers.**

Preview for **Zorin OS 18.1** and other **Ubuntu 24.04** based systems (x86_64),
and for the first time a **Windows** build made from the same code (portable
ZIP, see below). It upgrades earlier previews in place; settings and cloud
sign-ins are kept.

## Drive buttons

Quick Settings > **Show drive buttons above each panel** (off by default) puts
a row of buttons above each panel, like Total Commander's drive bar:

- **Linux**: System, Home, disks and USB drives (also unmounted ones: a click
  mounts), network shares and your cloud drives.
- **Windows**: the drive letters with Explorer's icons.
- A click opens the drive in that panel; the drive the panel is on is
  highlighted. Right-click: Open in Other Panel, Safely Remove / Eject, Hide
  This Button, Show Hidden Buttons.
- Snap images, `/boot`, AppImage and other system mounts get no button, and
  are gone from the drop-down drive list too.
- **Alt+F1 / Alt+F2** open the drive list of the left / right panel
  (Ctrl+Shift+Left/Right as before). On GNOME desktops such as Zorin OS the
  desktop keeps Alt+F1 and Alt+F2 for itself unless you free them in its
  keyboard settings.

## Multi-Rename (Ctrl+M)

Built into Panero, with Total Commander's patterns: `[N]`, `[E]`, parts such
as `[N2-5]`, the counter `[C]` (start, step, digits), `[P]` for the folder,
`[YMD]` and `[hms]` for the date and time. Search & replace with several
terms (`IMG_|DSC_`) and regular expressions, upper/lower case for name and
extension. The list shows every new name first; problems are red and nothing
is renamed until they are solved. Swapped names work, **Undo Last Rename**
works also after closing the dialog, and settings can be saved by name. With
KRename installed, *Open in KRename* hands the files over for its extras.

## Smaller changes

- Sort arrows: **^** ascending, **v** descending, on Linux and Windows alike
  (the systems drew them the other way round).
- Krusader's own sidebar inside each panel (the ^ button next to the free
  space, Alt+Down) is gone; Panero's sidebar stays.
- A cloud drive in the sidebar stays selected while the active panel is in
  it, and only then.
- Service menus that also copy the path no longer show a second "Copy path"
  next to Panero's own.

## Windows

Windows is now built and tested from the same code as Linux on every change.

- `panero-0.1.0-preview.11-windows-x64.zip` is a **portable** folder: unzip
  it and start `panero.exe`; nothing is installed.
- The file is not signed yet, so Windows SmartScreen warns on the first start
  (More info > Run anyway).
- Fixed: the window has normal minimize, maximize and close buttons; pinned
  folders use Explorer's icons like the panels; the right panel's outline no
  longer touches the window edge; Windows words (Recycle Bin, Settings); no
  Linux tool search on the first start.
- Not on Windows yet: cloud drives, Explorer's right-click menu (both planned
  for preview 12).

## Install (Linux)

```bash
sudo apt install ./panero_0.1.0.preview.11-1_amd64.deb
```

  suites, then on a fresh machine without MSYS2 the portable ZIP with a GUI
