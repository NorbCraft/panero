# Panero 0.1.0 preview 7

**Panero is an independent fork of Krusader. It is not affiliated with or endorsed by KDE or the Krusader maintainers.**

Bug-fix preview for **Zorin OS 18.1** and other **Ubuntu 24.04** based systems
(x86_64). It upgrades earlier previews in place; settings and cloud sign-ins
are kept.

## Fixed

- **OneDrive: "Failed to query root for drive … ObjectHandle is Invalid".** For
  some personal Microsoft accounts the list of drives contains a drive that
  cannot be opened, and rclone's setup always takes the first one. Panero now
  keeps the sign-in, asks Microsoft for the account's **main drive** and uses
  that one (the fix known from the rclone forum). If even that fails, Panero
  shows both errors, cancels the access and removes the half-made entry.
- Correcting the drive no longer restarts rclone's drive wizard (which would
  run into the same error again).

## Install

```bash
sudo apt install ./panero_0.1.0.preview.7-1_amd64.deb
```

## Tested

- ctest (7 suites, 42 cloud unit tests) and the 16 cloud security tests,
  including a browser sign-in against a local fake OAuth server where the
  OneDrive drive listing fails: the sign-in is kept and the drive is set
  without rclone looping.
- Package tests in clean Ubuntu 24.04 containers.

**Not tested**: sign-in to a real Microsoft account (the owner's test in
preview 6 found this bug).
