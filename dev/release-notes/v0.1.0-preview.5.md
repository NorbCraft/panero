# Panero 0.1.0 preview 5

**Panero is an independent fork of Krusader. It is not affiliated with or endorsed by KDE or the Krusader maintainers.**

Fifth preview of Panero for **Zorin OS 18.1** and other **Ubuntu 24.04** based
systems (x86_64). It upgrades earlier previews in place; settings are kept.

This preview is about **safe cloud sign-in** (audit and design:
`dev/CLOUD-SECURITY-AUDIT.md` in the source).

## New

- **Panero's own, up-to-date rclone.** Cloud drives now use rclone 1.76.0,
  shipped inside the package and checked against the official release
  checksums. Ubuntu's rclone 1.60.1 is no longer used: it is affected by
  CVE-2026-116194 (a web page could hijack a pCloud sign-in) and other 2026
  advisories.
- **Encrypted sign-ins.** Cloud sign-ins are kept in Panero's own, encrypted
  file (`~/.config/panero/cloud/rclone.conf`). The key is in your desktop
  keyring (GNOME Keyring on Zorin), which unlocks when you log in. Backups and
  copies of your home folder no longer contain readable sign-in keys.
  Passwords never appear in the process list.
- **Clear sign-in.** Before the browser opens, Panero tells you what access the
  provider grants: the drive's files only, never your e-mail, contacts or
  calendar, never your password. Google Drive and OneDrive can be added
  **read-only**; OneDrive asks only for your own files by default.
- **Real sign-out.** **Sign Out and Remove** cancels Panero's access at Google,
  Dropbox, Box and pCloud and deletes the sign-in and downloaded files. For
  Microsoft and Nextcloud, Panero shows the page where you remove the access.
  **Sign Out of All Clouds** does this for every drive at once.
- **Offline files** for cloud drives:
  - files you open stay **available on this device** (green outline check);
    the rest are **online-only** (cloud badge);
  - **Keep on This Device** on a folder keeps a synchronised local copy in
    `~/Cloud Offline/`, also without internet; **Free Up Space** removes it;
  - **Offline Files…** on a cloud drive: kept folders, their state, *Sync
    Now*, the space for opened files.
- **Import from rclone** moves remotes from your own rclone setup into the
  encrypted store; **Other services** opens rclone's setup in a terminal,
  stored encrypted too.
- **MEGA** is no longer in the guided list: its password is also the key to all
  your MEGA files, and Ubuntu's rclone could not use MEGA anyway.

## Install

Download `panero_0.1.0.preview.5-1_amd64.deb` below (package version
`0.1.0~preview.5-1`; GitHub shows `~` as `.` in file names) and open it with the
Software installer, or in a terminal in the download folder:

```bash
sudo apt install ./panero_0.1.0.preview.5-1_amd64.deb
```

Cloud drives need `fuse3` (recommended by the package) and a desktop keyring
(GNOME Keyring is part of Zorin). The `rclone` package of the system is not
needed and not used.

Uninstall: `sudo apt remove panero`.

## Tested

- **Automated tests**: ctest, 7 suites; 41 cloud unit tests.
- **Cloud security tests** (15, in CI on every change) in a private keyring
  session with a temporary home folder:
  - no password, token or key appeared in any process's command line or
    environment (a scanner read all processes throughout; a positive control
    proves it catches leaks);
  - no secret in any file afterwards; the configuration is encrypted, 0600;
  - the pCloud sign-in hijack (CVE-2026-116194) is rejected by the bundled
    rclone;
  - Nextcloud/WebDAV sign-in against a local server;
  - a test drive mounted, files opened (available offline), a folder kept
    on this device, changes synchronised both ways, an interrupted sync
    repaired without losing a local edit, Free Up Space, import from rclone,
    missing keyring key.
- **Independent security review** of the change (two rounds); its findings are
  fixed (see `dev/LOG.md`).
- **Package tests** in clean Ubuntu 24.04 containers (93 checks): install,
  coexistence with Krusader, upgrade from preview 4, remove/purge; the
  installed rclone is byte-identical to the official 1.76.0 release.

**Not tested**: signing in to real Google, Microsoft, Dropbox, pCloud or Box
accounts (no accounts available to the developer). The sign-in was checked up
to the provider's page; revocation and the account check were tested against
recorded provider answers, not live accounts. Please try a throwaway or
read-only sign-in first.

See the preview 1 release notes for the full feature list and known limitations.
