# Panero 0.1.0 preview 4

**Panero is an independent fork of Krusader. It is not affiliated with or endorsed by KDE or the Krusader maintainers.**

Fourth preview of Panero for **Zorin OS 18.1** and other **Ubuntu 24.04** based
systems (x86_64). It upgrades earlier previews in place; settings are kept.

## New

- **Cloud section** in the sidebar (switch it off in Quick Settings if you don't
  need it):
  - **Add Cloud…**: Google Drive, OneDrive, Dropbox, pCloud, Box, MEGA and
    Nextcloud/WebDAV through the free *rclone* tool. Panero offers to install
    rclone if needed. You sign in in your browser, and the drive then opens in a
    panel like a folder.
  - **Connect to Server…**: WebDAV (Nextcloud/ownCloud), SFTP, Windows
    shares/NAS and FTP.
- **Quick Settings** (cogwheel, formerly View & Colors):
  - **Icons**: system or **Panero Line** (thin line icons).
  - **Folder color**: presets or a custom colour.
  - **Menus**: Menu button or the classic menu bar, so Alt+letter navigation is
    available again.
  - **Hold feedback** while holding the right button: pie, ring, bar or off.
  - **Transparent** cursor fill (frame only).
  - Changing the appearance asks to **restart** Panero, because live switching
    left parts of the old theme behind. Folders and tabs are kept.
- **Progress in the panel**: copy, move and delete show a slim progress bar in
  the bottom row of the receiving panel, with Details and Cancel. No more
  separate progress windows.
- **Pie feedback** next to the pointer while you hold the right button, until
  the context menu opens.
- **Context menu**: **Copy Path** and **Open Terminal Here**.
- **Tabs**: the tab bar appears with the second tab, and the new-tab button sits
  next to the path.
- **Window title** shows the folder: "Projects — Panero".

## Fixed

- **F9 Term** failed on GNOME/Zorin because Konsole is not installed. Panero now
  uses the desktop's terminal.
- **New tab** showed an error "Malformed URL /.".
- **After F7 New Folder** the keyboard stayed on the function key bar. Now the
  cursor is on the new folder, and Enter opens it.
- **Toolbar**:
  - The Details | Thumbnails control is rounded, with equal halves also when
    text is shown under icons.
  - The sidebar button is as tall as the others.
  - The empty extra toolbar is gone.
  - The move handle is visible when the toolbar is unlocked.
  - The ☰ button is called "Menu".
- **Rename field** blends into the row.
- **Marked files**: no check badge by default (red text and background stay).
  The badge can be switched on in Quick Settings.

## Install

Download `panero_0.1.0.preview.4-1_amd64.deb` below (package version
`0.1.0~preview.4-1`; GitHub shows `~` as `.` in file names) and open it with the
Software installer, or in a terminal in the download folder:

```bash
sudo apt install ./panero_0.1.0.preview.4-1_amd64.deb
```

Cloud drives need `rclone` and `fuse3`; Panero offers to install them the first
time you use **Add Cloud…**, or run `sudo apt install rclone fuse3`.

Uninstall: `sudo apt remove panero`.

## Tested

- **Automated tests**: ctest, 6 suites, including the new cloud tests.
- **GUI file operation test**: 17/17 on Zorin OS 18.1 under Xvfb.
- **Driven in the real app under Xvfb**:
  - the progress row during a 1.6 GB copy;
  - text under icons;
  - the rename field;
  - Quick Settings, the restart prompt and the restart itself;
  - the Panero Line icons and folder colours;
  - an rclone drive (test remote) mounted from the Cloud section and opened,
    and unmounted on exit;
  - F9, new tab and F7.
- **Package tests** in clean Ubuntu 24.04 containers: install, coexistence with
  Krusader, upgrade from preview 3, remove/purge.

**Not tested**: signing in to real cloud accounts (Google, Microsoft, Dropbox,
pCloud, Box, MEGA). No test accounts were available. The sign-in step was
checked up to the point where the browser opens the sign-in page.

See the preview 1 release notes for the full feature list and known limitations.
