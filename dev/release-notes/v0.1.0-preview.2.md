# Panero 0.1.0 preview 2

**Panero is an independent fork of Krusader. It is not affiliated with or endorsed by KDE or the Krusader maintainers.**

Second preview of Panero for **Zorin OS 18.1** and other **Ubuntu 24.04** based
systems (x86_64). It upgrades preview 1 in place; settings are kept.

## Changes since preview 1

- **Sidebar button** moved to the far left of the toolbar (icon only, with the
  desktop's sidebar icon).
- **Trash** button opens a menu: **Open Trash** or **Empty Trash** (asks first).
- **Details | Thumbnails** is one segmented button that shows the active view and
  switches to the other one when clicked.
- **Pinned** and **Folders** in the sidebar can be resized by dragging the handle
  between them; folders can be **dragged onto Pinned** to pin them.
- **Folder tree** start: simply **Home** (or the drive / `/` when outside Home) or
  the **whole file system (/)**.

## Install

Download `panero_0.1.0.preview.2-1_amd64.deb` below (package version
`0.1.0~preview.2-1`; GitHub shows `~` as `.` in file names) and open it with the
Software installer, or in a terminal in the download folder:

```bash
sudo apt install ./panero_0.1.0.preview.2-1_amd64.deb
```

Uninstall: `sudo apt remove panero`.
