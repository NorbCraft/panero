# Reference notes

- `details-dark.png`: dark appearance reference.

## Written requirements take precedence

The concept predates the latest decisions. The implementation must use a `.deb` release only, support smaller row heights (roughly 18–20 logical px where metrics permit), show subtly colored modern icons, and offer configurable alternating row backgrounds. Keep the real Krusader context menu on held right-click and the original column chooser on ordinary header right-click. Preserve original menus/functions instead of the prototype's simplified menu set. The command line is hidden by default.

The prototype contains fake file lists, sample selection counts, simulated operations/context menus/comparisons, and illustrative thumbnails. These are not functionality, test evidence, or a promise of native CAD preview support. Its Krusader title is historical: the implemented product is Panero.

## Selected icon direction

Preserve the recognizable blue/teal folder silhouette with a central split suggesting two file panels, an understated folder tab, clean rounded geometry, and restrained tonal depth. Keep it readable at 16, 22, 24, 32, 48, 64, 128, and 256 px, in light/dark launchers. Avoid letters, tiny details, and imitation of upstream branding. Produce a clean editable SVG and raster exports as needed; the attached raster is a design reference, not a finished icon system.

The icon concept was AI generated in this design conversation and selected by the user. Do not invent exclusive authorship/copyright or trademark clearance. Record provenance and permissions of the final asset accurately.
